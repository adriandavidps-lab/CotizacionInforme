# NotebooksStore · Cotizaciones e informes técnicos

App web para armar cotizaciones e informes técnicos de NotebooksStore en PDF (con logo, sello y firma) y enviarlos por WhatsApp. Funciona en la PC y en el celular, y se sincroniza con una hoja de Google privada.

Este repositorio no contiene datos de clientes, ni la firma, ni la clave: eso vive en el script de Google del dueño.
